形象素材目录（插件按文件名扫描，不写死清单）。

命名规则
  look-<序号>.jpg              该形象的静图（底图 / 片段缺席时的兜底）
  look-<序号>.<动作名>.mp4     该形象某个动作的循环片段，可多动作并存
  look-<序号>.gif / .webp …    动图或其它静图格式同样支持

例：
  look-01.jpg
  look-01.breathe.mp4
  look-01.hair.mp4
  look-02.jpg
  look-02.breathe.mp4

序号可扩展（look-03、look-04…），丢文件进来就生效，不需要改代码。
宿主半每次请求现扫清单，所以**刷新页面即可**，不用重启。

片段必须是**首帧 = 末帧**（同一张图同时作首末帧），否则播到头会弹回起始帧。
首末帧一致还有个好处：任意多条片段串接都不跳，因为 A 的末帧 = B 的首帧。

常驻与动作
  breathe / breatheSlow / blink 被当作**常驻**动作（几乎不动，只是安静待着）；
  其余都算**会吸引注意力**的动作，只在偶尔与点击时触发。
  常驻状态占绝大部分时间，选哪一条由配置项 idleAction 决定（默认 breathe）。
